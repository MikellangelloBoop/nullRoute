# Сетевые матчи Null Route

Запуск проверенной сетевой версии: `PlayOnline.cmd` (сборка `Releases/Online`). Она отделена от параллельной доработки классов и моделей.

В меню игры: **Сетевые операции**. Можно обновить LAN-список, сохранить IPv4/домен с портом, подключиться напрямую или запустить свой сервер отдельным процессом. Избранное сохраняется в пользовательской конфигурации. Адрес VPS для текущего развёртывания — `201.51.19.38:7777`.

Список получает имя, карту, количество игроков, вместимость, фазу и время ответа через UDP. Игровой порт — **7777/UDP**, порт запросов — **7778/UDP**. При другом игровом порте порт запросов равен игровому + 1; автоматический LAN broadcast использует стандартный 7778. Отсутствие ответа в списке не запрещает прямое подключение: порт запросов может быть закрыт отдельно.

Совместимость списка проверяется по версии протокола 2. Сам Unreal дополнительно проверяет совместимость сетевой сборки при подключении. Данные клиента не определяют вместимость или команды: окончательное решение принимает сервер.

## Раунд

- Сетевой сервер ждёт минимум двух игроков с представителями обеих команд.
- Подготовка длится **45 секунд**. Атака находится в стартовом отсеке; защита готовит площадку и строит реальные ноды. Граница контролируется сервером и прогнозируемым движением клиента.
- У обеих сторон есть тренировочные мишени и верстак пополнения боекомплекта (**F**). Попадания по мишеням не дают денег и убийств. Урон игрокам, захват цели и разведывательный перехват заблокированы до боя.
- Перед боем боекомплект восстанавливается до конечного лимита, ворота открываются, тренировочные пули удаляются. Построенные ноды и связи сохраняются вместе с расходами на них.
- Подключившийся во время боя ждёт следующей подготовки, не получает дополнительную жизнь. Заполненный сервер возвращает `SERVER_FULL`.
- Максимум — 10 игроков. После завершения матча через 15 секунд начинается новый матч; при отсутствии обеих команд сервер возвращается к ожиданию.

## Свой сервер Windows

Из корня проекта запустите `StartServer.cmd`. Либо:

```powershell
.\Scripts\StartServer.ps1 -Port 7777 -MaxPlayers 10 -PreparationSeconds 45 -Name Friends
```

Откроется отдельный процесс без графики; скрипт выведет PID и путь к журналу. Он продолжает работать после закрытия терминала. Завершайте только указанный PID. Для редакторского запуска доступен параметр `-Editor`.

Сервер, запущенный кнопкой внутри игры, принадлежит этому экземпляру игры и останавливается при его закрытии. Удалённый VPS этой кнопкой не останавливается. Для подключения извне локальному серверу нужны доступные UDP-порты и соответствующее перенаправление на роутере.

## VPS

Текущее окружение: Ubuntu 26.04, 2 vCPU, 4 ГБ RAM. Установленная локально поставка UE не содержит Linux server toolchain. Для проверки сетевых матчей используется Windows Game-сборка в режиме `-server -nullrhi -nosound` через Wine 10, под непривилегированным пользователем `nullroute`. Это тестовое развёртывание; нагрузочная проверка 10 игроков на 64 Гц ещё требуется. Нативный Linux Dedicated Server требует отдельной сборки движка и серверной цели.

Служба `nullroute.service` перезапускается при сбое и включена на старте ОС. Игровые файлы: `/opt/nullroute/current`, журнал: `/opt/nullroute/logs/server.log`.

```sh
systemctl status nullroute
journalctl -u nullroute -n 80 --no-pager
systemctl restart nullroute
systemctl stop nullroute
```

Пароли SSH не включаются в исходники, конфигурацию или сборку. Предыдущие адреса VPS не используются.

## Проверки

`Scripts/TestServerBrowser.py` запускает настоящий сервер и четыре клиента: ожидание одного игрока, подготовка при двух, автоматический старт боя, очередь позднего игрока и отказ четвёртому при тестовом лимите 3. `--packaged` использует распространяемую сборку. Процессы теста завершаются в `finally`.

`Scripts/TestPreparation.ps1` проверяет ворота и движение двух команд до и после подготовки. Встроенные `-NRPreparationTest` и `-NRServerSystemTest` проверяют игровые правила, ограничения адресов, сохранение списка и настоящий UDP-обмен.

Подробности лицензий голосов сохранены в `Releases/Online/VOICE-LICENSES.md`; тестовое сетевое развёртывание не меняет условия их использования.

## Проверка публичного сервера

20.09.2026: два отдельных клиента подключились к `201.51.19.38:7777`, получили разные команды, прошли 45 секунд подготовки и автоматически вошли в бой. VPS подтвердил лимит 64 Гц, автозапуск службы, отсутствие аварийных перезапусков и около 741 МиБ памяти в момент измерения. Полная нагрузка 10 игроков не измерялась.

Все участники должны использовать комплект `Releases/Online` или архив `Releases/NullRouteOnline.zip`. Основная сборка с параллельными изменениями классов может отличаться.
