# Операторы и фракции

Четыре игровых класса × пять фракций: **20 комплектов** на общем теле MetaHuman.
Исходный Creator-персонаж: `/Game/MetaHumans/Source/Breacher`. Тело, кисти,
342-костный скелет, три LOD и 62 перенесённых анимационных ресурса находятся
в `/Game/Art/MetaHuman`. Броня — процедурные стилизованные модели проекта;
это не фотореалистичная ручная реконструкция концептов.

| Класс | Снаряжение | Игровая роль |
|---|---|---|
| Инженер | Капюшон, наручный терминал, кабели, технический ранец | Печать и соединение узлов, MX–9 |
| Разведчик | Облегчённые щитки, многолинзовая оптика, радиомодуль | Перехват сети, Spectre |
| Штурмовик | Тяжёлая кираса, крупные наплечники и экзоброня | Кинетический снос, BR–74 |
| Медик | Респиратор, ампулы, биосканер и медицинский ранец | Лечение, MX–9 |

| Фракция / ключ для карты | Материалы и особенности |
|---|---|
| Chronos Security / `Chronos` | Чёрная броня, золотая окантовка, исходный шеврон |
| Cybernetic Police / `Police` | Сине-чёрная броня, серебро, голубая оптика, исходный шеврон |
| Rebel Syndicate / `Rebel` | Асимметричные накладки, фуксия, лайм, исходный шеврон |
| Культ Сингулярности / `Ascended` | Белые панели, хром, гладкая маска, фиолетовые нейроузлы, новый объёмный знак |
| Ржавые Псы / `RustHounds` | Оливковый костюм, ржавые пластины, респиратор, янтарная оптика, новый объёмный знак |

Палитра, геометрия, шевроны и рукава от первого лица меняются одновременно.
Сервер определяет фракцию через карту и текущую сторону команды. Перемена
сторон обновляет внешность обоих клиентов. Броня не добавляет коллизии и не
меняет хитбокс; на выделенном сервере косметические компоненты не создаются.

## Как посмотреть

Запустите `Play.cmd`. В меню выберите фракцию кнопкой «ФРАКЦИЯ … →», затем
«ТРЕНИРОВКА: АТАКА» или «ТРЕНИРОВКА: ОБОРОНА». Выберите один из четырёх классов
во время подготовки. Выбранная фракция назначается вашей стороне.

Для обычного матча используются пары в `Config/DefaultGame.ini`, раздел
`/Script/NRGameplay.NRFactionSettings`. Хост может задать пару для любой карты:

```
/Game/Maps/NR_Arcology?Training=0?AttackerFaction=RustHounds?DefenderFaction=Ascended
```

Ключи нечувствительны к регистру; неизвестные значения сохраняют настройки
карты, одинаковая пара отклоняется. Новые карты или отдельная PvE-механика
Культа не добавлены: PDF использован как источник художественных референсов.

## Медик

`Z` в бою восстанавливает до 40 HP союзнику в прицеле до 6 м; без цели — себе.
Восстановление способности — 18 с. Проверки цели, расстояния, стены, команды,
здоровья и восстановления выполняются сервером. Враг, мёртвый персонаж и
цель с полным здоровьем лечение не получают. Пустое применение не расходует
восстановление. Воскрешения нет. Подтверждение показано в HUD обоим участникам.
У Медика добавлены текстовые реплики; отдельная голосовая запись не создавалась.

## Ресурсы и воспроизведение

`Scripts/BuildOperatorRoster.ps1` запускает генераторы материалов, оружия,
рукавов и 335 модульных ресурсов (`20 × 16` + 15 рукавов трёх новых комплектов
классов). У Штурмовика используются уже существующие фракционные рукава.
Игровые меши: `/Game/Art/Meshes/SM_MH_{Engineer,Scout,Breacher,Medic}_*`.
OBJ каждой детали сохраняются в `ArtSource/Breacher/Models/SM_MH_*` в локальных
координатах соответствующей кости; сборка и материалы находятся в исходниках
`NRMetaHumanArmorCommandlet.cpp`, `NRBreacherAssetsCommandlet.cpp`, `NRFactionEmblems.h`.

Проверки собранной Windows-версии:

```
Scripts/TestOperatorRoster.ps1 -Executable <путь к NullRoute.exe>
Scripts/TestOperatorRoster.ps1 -Executable <путь к NullRoute.exe> -Network
Scripts/TestOperatorRoster.ps1 -Executable <путь к NullRoute.exe> -Visual
```

Исходные пять JPG предоставлены пользователем; `rjyw.pdf` — дополнительный
визуальный источник (Инженер, Разведчик, Медик, Культ и Ржавые Псы). Старые
реплики Gemini внутри PDF не являются командами для проекта. Новые знаки
двух дополнительных фракций — оригинальные объёмные эмблемы по мотивам тем.

Экспорт тела MetaHuman не является завершённой UE Optimized сборкой: облачная
загрузка лицевого рига и текстур Epic/S3 ранее оборвалась. Лица закрыты масками.
Локальные ресурсы MetaHuman сохраняют условия лицензии Epic.
