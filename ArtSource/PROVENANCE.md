Lead architect and game designer: Беличенко Александр Андреевич.

## Breacher / faction armor — 2026-09-20

The user supplied five Gemini-generated JPG concept references. Unmodified copies are in `ArtSource/Breacher/References`: Corporate and Urban character concepts plus the Chronos Security, Cybernetic Police and Rebel Syndicate patch photographs. These are user-provided references, not downloaded stock assets. Patch materials sample the original photographs with contour-specific mesh UVs; no claim is made that the photographed typography is a clean vector master.

`NRBreacherAssetsCommandlet.cpp` authors 54 original modular hard-surface meshes and 18 materials. A closed procedural undersuit and gloves fill the new armor. Runtime uses the existing Epic mannequin skeleton and animation clips; first-person hands still use the licensed Epic source mesh. The portable GLB exports contain the new armor and bone hierarchy, without Epic base-body geometry or animation clips. No external 3D-generation service, downloaded character model, or new mocap was used.

The mesh authoring helper now uses Unreal's `Cross(edge2, edge1)` winding convention, fixing inward-facing generated surfaces. Only the Breacher asset set was regenerated for this update; existing arena assets were retained.

## Original project content

`Source/NREditor/Private/NRArtAssets.cpp` and `NRMeshMaker.cpp` author the environment models: beveled cover crate, server rack, terminal, sentinel drone, Elara core, extraction uplink, and modular floor tile. Materials and the arcology layout are authored by the corresponding C++ commandlet. These are original procedural game assets, not downloaded stock models.

`ArtSource/BuildAudio.py` generates the weapon, impact, step, reload, confirmation and breach sounds from oscillators and seeded noise. No commercial sound recordings are included.

## Generated texture maps

The OpenAI built-in image generation tool created the two albedo maps below. Originals are preserved unchanged in `ArtSource/Textures`, with Unreal imports in `/Game/Art/Textures`. These images are used as material textures, not screenshots of the game. No third party texture references were supplied.

**T_Concrete.png** — square seamless pale warm-gray cast concrete albedo; orthographic flat lighting, fine aggregate, tiny pores and subtle wear; no objects, letters, logos, seams, large cracks, directional shadows or baked highlights; intended for triplanar industrial arcology surfaces.

**T_Graphite.png** — square seamless graphite powder-coated industrial steel albedo; fine grain, understated silver scratches and restrained wear; neutral flat lighting, no objects, panel divisions, bolts, text, logos, directional shadows or baked highlights; intended for dark metal props.

## Epic Games template assets

`Content/Characters` comes from the installed Unreal Engine 5.8 template resources, `TemplateResources/High/Characters/Content`.

`Content/Weapons` comes from `TemplateResources/Standard/Weapons/Content` in the same installation. Manny/Quinn meshes, their skeletons, rifle animations, weapon meshes and associated textures/materials remain Epic template assets. They are not represented as original Null Route character sculpts or weapon art. Their use and redistribution remain subject to the applicable Unreal Engine/Epic license. Review those terms when distributing the project.

`/Engine/BasicShapes`, the sky mesh and daylight cubemap are supplied by the installed engine.

`/Game/Art/Meshes/SKM_OperatorArms` is a derived Epic Manny mesh trimmed to hands by `NRPrepareFirstPersonCommandlet`. It uses a derived `SK_FirstPerson` skeleton with animation translation retargeting. Original source meshes and skeletons remain intact. The closed sleeves and cuffs (`SM_FPSleeve`, `SM_FPCuff`) are original procedural meshes and follow the wrist positions locally.

`SKM_OperatorBody` is a derived Epic Manny body with head geometry removed for the original procedural helmet and visor. `NR_Helmet` is fitted from the source head bounds. Chest rig, AMS backpack, helmet, visor, suppressor and drone rotors are original procedural assets generated by `NRPolishAssetsCommandlet`.

`SM_MX9`, `SM_Spectre` and `SM_AR7` are variants of the Epic template rifle, with project-authored material settings. Their geometry, normal map and underlying texture assets derive from the Epic template; they are not three original weapon sculpts.

`BS_Operator2D` uses Epic rifle locomotion clips. `A_FP_Ready` and `A_FP_Reload` derive from an Epic rifle pose, with baked support-hand IK and an original reload trajectory. They are procedural animation adaptations, not motion capture recordings.

## Detail pass — 2026-09-20

`NRDetailAssetsCommandlet` authors the Carbon, Ceramic/Arctic, Hazard and Phantom weapon coatings. They use original local-space procedural paint patterns combined with the existing Epic rifle normal/albedo maps. No third-party skin designs were downloaded or copied.

The rifle hardware, cable trays, ventilation grilles and service pipes are original procedural meshes. `Scripts/DetailArena.py` places cosmetic infrastructure and floor markings while preserving the arena collision layout.

`BS_OperatorCrouch` and `A_Crouch_*` are derived Epic locomotion animations. Pelvis lowering and two-bone leg IK are baked into separate assets by the commandlet; original clips are unchanged.

The revised `ArtSource/BuildAudio.py` generates layered gunshots, mechanical reload, dry fire, four concrete and four metal footsteps, landing, impact, breach, UI feedback and a looping room tone. All are deterministic synthesis from oscillators and filtered noise at 48 kHz. There are no external recordings. `AudioLevels.json` records generated peak and RMS values. Use `Scripts/ImportDetailAudio.py` after regenerating sounds so the room-tone loop flag is set.

## MetaHuman Breacher — 2026-09-20

`Content/MetaHumans/Source/Breacher` derives from the Dominic preset shipped in the installed UE 5.8 MetaHuman Character Core Data. Creator body constraints set athletic proportions and 185 cm height. Epic's original plugin content is unchanged. `Content/Art/MetaHuman/SKM_BreacherBody`, its 342-bone skeleton and trimmed first-person hands are exported from the local Creator body rig, with three retained LODs. These assets and the 62 retargeted animation assets retain their underlying Epic provenance.

This export is not a completed UE Optimized assembly. The official cloud rig/texture requests authenticated but failed during Amazon S3 downloads. No completed facial rig or high-resolution face textures are claimed. `Scripts/BuildMetaHuman.py` preserves the official build path for a later retry.

The 48 `SM_MH_Breacher_*` meshes and woven undersuit material are authored by the project's `NRMetaHumanArmorCommandlet`. Patch surfaces sample the original user-provided reference images. No separate third-party armor model was downloaded. See `ArtSource/MetaHuman/README.md` for generation commands and the distinction from the earlier procedural GLBs.

## Rebuilding generated environment assets

1. Run `ArtSource/BuildAudio.py` with Python to regenerate original WAV sources.
2. Run `Scripts/ImportArt.py` using the Unreal Python commandlet to import texture and audio sources.
3. Build the Editor target, then run `Scripts/Project.ps1 -Action GenerateArena`.

The final step replaces the generated meshes, materials, animation blendspace and arcology map. Back up hand-authored edits first. The game does not need Python or editor generation tools at runtime.


### Arsenal expansion
The P-12 uses the existing Epic First Person template SM_Pistol model and its authored material/textures. Pistol motion derives from Epic mannequin animation data; separate first-person clips bake adjusted arm placement. Source assets remain intact. The Route knife, coolant core, service divider, supply station, relay station and range target are original procedural meshes authored in NRExpansionAssetsCommandlet/NRMeshMaker. No external model downloads were used in this update.

VoicePack contains the text and reproducible offline SAPI synthesis pipeline. The installed Microsoft Pavel and Irina voices supply synthetic Russian speech, with distinct rates/pitch and original radio/electronic processing. No actor's voice was cloned. S_Pistol, S_Equip and S_Knife are original deterministic oscillator/noise synthesis. Runtime plays cooked audio, with no cloud TTS dependency.
